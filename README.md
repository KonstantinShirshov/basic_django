# Проект Интернет-магазин

## Описание:

Проект интернет-магазина с самыми лучшими товарами.
Также добавлен блог об отдыхе, туризме и спорте.
В интернет-магазине добавлена возможность добавлять свои товары авторизованным пользователям.

## Установка:

Клонируйте репозиторий:
```
git clone https://github.com/KonstantinShirshov/basic_django
```
Запустите сервер: 
```
python manage.py runserver

```
